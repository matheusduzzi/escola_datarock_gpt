# Direitos antes de abrir ao público

Protótipo: passeio pela loja do Centro da Loja Aurora
Endereço privado: https://loja-aurora-centro.example/
Checado em: 08/11/2026

## Arquivos

Um arquivo, ou um padrão como `sprites/*.png`, por linha. Só vai para a `dist/` o que tem "publicar".

| arquivo | o que é | origem | licença ou autorização | crédito onde | decisão |
|---|---|---|---|---|---|
| `*.html` | as páginas do passeio | escritas com o Codex nesse projeto | nossas | - | publicar |
| `*.css` | o estilo das páginas | escrito com o Codex nesse projeto | nosso | - | publicar |
| `*.js` | o código do passeio | escrito com o Codex nesse projeto | nosso | - | publicar |
| `bairro-data.js` | dados de mapa: ruas, prédios e lugares do bairro | OpenStreetMap e Overture, baixados pelo script da aula de mapas | ODbL, CC BY 4.0 (parte dos prédios) e CDLA Permissive 2.0 | tela e README | publicar |
| `sprites/*.png` | os quatro móveis da loja | gerados no ChatGPT e aprovados na aula de arte | nossos | - | publicar |
| `referencias/vitrine-do-mapa.png` | foto da vitrine | print de uma foto que um usuário publicou no mapa | de quem tirou a foto | - | publicar |
| `teste.cjs` | o teste do portão | escrito com o Codex nesse projeto | nosso | - | fica fora |
| `README.md` | o leia-me do projeto | escrito com o Codex nesse projeto | nosso | - | fica fora |
