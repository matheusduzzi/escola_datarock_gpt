# Passeio pela Loja Aurora

O passeio pela loja do Centro, visto de cima, e a página Como chegar.

- `index.html`: o passeio. `pagina.html`: a página Sobre. `mapa.html`: Como chegar.
- `teste.cjs`: o teste do portão (`node teste.cjs`).
- `referencias/`: material para olhar, que não vai para a página publicada.
